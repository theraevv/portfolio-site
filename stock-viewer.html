Stock Viewer

Open the live Streamlit app for stock analysis and visualization.

How to Use

Open the public Streamlit app or run it locally if you prefer.

Live Streamlit App

The Stock Viewer app is deployed publicly on Streamlit Community Cloud. Click the button below to open the live app now.

Open Live App

Run Locally (Optional)

You can still run it locally from stock_viewer.py if needed.

  1. Open a terminal in the project folder.
  2. Install dependencies: python -m pip install -r requirements.txt.
  3. Run streamlit run stock_viewer.py.
  4. Open the app at http://localhost:8501.
