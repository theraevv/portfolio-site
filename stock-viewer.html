Stock Viewer

Launch the local Streamlit app for stock analysis and visualization.

How to Use

Start the app locally, then open it from the browser.

Local Streamlit App

The Stock Viewer app is available in stock viewer.py. Run it with Streamlit to view stock data locally.

  1. Open a terminal in the project folder.
  2. Run streamlit run "stock viewer.py".
  3. Open the app at http://localhost:8501.

If your local app is already running, click the button below to open it.
